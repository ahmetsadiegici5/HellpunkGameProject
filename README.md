# Hellpunk

Unity ile yaptığım gitar ve ritim temalı bir 2D platformer oyunu.

Oyunda yetenekler tek tuşla değil, ekranda çıkan kısa bir yön tuşu dizisini (örneğin `↓ ↑ ←`) 3 saniye içinde doğru girerek kullanılıyor. Dört bölüm, farklı düşmanlar, bir boss, dükkân ve checkpoint sistemi var.

## Kontroller

`A/D` hareket, `Space` zıplama, `Shift` dash, sol tık saldırı, `Q` fireball, `F` iyileşme, `R` zaman yavaşlatma, `U` ultimate, `G` dükkân, `Esc` duraklat.

## Çalıştırma

Unity 6000.1.17f1 ile açıp `Assets/Levels/MainMenu.unity` sahnesinden başlatılabilir.
